windows app

Portable, no python install needed. Unzip anywhere and run launch.bat. Ships with the bundled runtime.

download for windows

quick start

  1. flash firmware to your board, or use test mode in the app with no hardware
  2. unzip the windows app and run launch.bat
  3. keep test mode off for real use, pick your board's com port, connect
  4. select an app in the list, record gestures, done

browser flashing needs chrome or edge. run with a console for debugging: src\runtime\python\python.exe src\main.py

troubleshooting

port won't open close arduino ide or serial monitor first; they hold the com port
no data from port wrong port selected, or firmware not flashed; unplug other boards
button does nothing wrong pin for the board, or the button isn't wired to gnd
flash blocked chrome/edge only; firefox and safari don't support web serial
